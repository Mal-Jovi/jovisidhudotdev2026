# jovisidhudotdev2026

My personal portfolio site — built to showcase my work in web and mobile front-end development.

The react app is hosted live using Netlify here: jovisidhu.dev

## Built With

- **React** (v19) & **React Router** (v7)
- **Vite** (v8)
- **Bun** for package management and running scripts
- **ESLint** (v10) for linting
- **Adobe Fonts (Typekit)** for typography

## Running Locally

```bash
bun install
bun run dev
```

Other scripts you might need:

- `bun run build` — build for production (`dist/`)
- `bun run preview` — preview the production build locally
- `bun run lint` — run ESLint
